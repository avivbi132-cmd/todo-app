Todo - Privacy policy

Todo is a private assistant used only by the members of one household. It is not offered to the public.

What Google data it accesses

Only with the signed-in user's own consent: that user's Gmail messages and Google Calendar events.

How the data is used

To write that user's morning summary and reminders, posted only to that user's private chat channel. Email and calendar content is sent to an AI model only to write that summary.

Storage and sharing

Sign-in tokens are stored on the owner's own computer. Google user data is not sold, not shared with anyone else, and not used for advertising or to train AI models.

Removing access

Any user can remove Todo's access at any time at myaccount.google.com/permissions.
